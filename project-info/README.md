# project-info

Everything about this project that is not code. This README explains what is in each folder.

| Folder | What goes in it |
|---|---|
| `docs/` | Requirements, specifications, architecture notes, decisions, meeting notes |
| `design/` | Sample designs: mockups, wireframes, screenshots, design references |
| `poc/` | Proofs of concept built before the main project (one subfolder per POC) |
| `testing/` | Testing methods: test plans, test cases, manual checklists, test results |
| `pages/` | Page/screen descriptions: what each page shows and does |
| `sub-docs/` | Other supporting documents specific to this project |

Keep this table up to date when you add a folder or an important document.
