# Site map

Every page exists in Thai (`/th/...`, default) and English (`/en/...`).

| Page | URL | What it shows and does |
|---|---|---|
| Home | `/` | Campaign hero, best sellers, shop by category (Lips, Face, Eyes, Lashes, Sets), shade finder teaser, brand story, tutorials, reviews, Instagram/TikTok strip, LINE sign-up |
| Category | `/shop/[category]` | Product grid, filters (shade family, finish, skin type, price, long-wear/waterproof), sorting |
| Product | `/product/[slug]` | Gallery with zoom and video, shade swatches on 3+ skin tones, price in ฿, delivery estimate, add to bag, how to use, ingredients, Thai FDA (อย.) notification number, reviews with photos, "complete the look" |
| Sets and gifts | `/gifts` | Makeup kits, gift sets, gift wrapping and message option |
| Shade finder | `/shade-finder` | Short quiz (skin tone, undertone, finish) → recommended shades |
| Search | `/search` | Instant results with product images, Thai and English keywords |
| Bag | drawer on every page | Items, shade, quantity, free-shipping progress bar, upsell |
| Checkout | `/checkout` | Guest checkout, Thai address form (province → district → subdistrict → postcode), delivery choice, PromptPay / TrueMoney / Rabbit LINE Pay / card |
| Order complete | `/order/[id]` | Thank you, order summary, add LINE to track order |
| Account | `/account` | Orders, addresses, wishlist, saved shades |
| Wishlist | `/wishlist` | Saved products, works for guests too |
| Beauty journal | `/journal` | Tutorials and looks (e.g. Songkran waterproof look) with shoppable products |
| About | `/about` | Brand story, values, ingredients philosophy |
| Help | `/help` | Shipping, returns, payment methods, FAQ |
| Contact | `/contact` | LINE Official Account, Facebook Messenger, email, phone |
| Legal | `/privacy`, `/terms`, `/cookies` | PDPA privacy notice, terms, cookie settings |

Add a file per page in this folder (e.g. `product.md`) when its design is worked out in detail.
